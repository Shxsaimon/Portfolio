## Opção A: Variante 1 — "Deep Violet Elegance" (Roxo Elétrico para Roxo Escuro)
*Recomendada: visual mais sóbrio, corporativo e com profundidade de tons noturnos.*

```text
Design a modern, high-end personal portfolio landing page for Saimon Furigo, a Full Stack Developer with strong UX/UI craft and end-to-end software architecture expertise.

Visual Identity & Design Tokens:
- Theme: Dark luxury tech aesthetic (obsidian and deep plum undertones).
- Background Canvas: #0A090D (Deep Obsidian).
- Surfaces & Cards: #14121A with subtle 1px border #282236 and soft ambient shadow.
- Primary Brand Color: #6F00FF (Electric Violet).
- Secondary / Hover Color: #340094 (Deep Indigo / Dark Violet hover state).
- Hero Gradient Accent: linear-gradient(135deg, #6F00FF 0%, #340094 100%) applied to headline text and main CTA button.
- Typography: "Plus Jakarta Sans" or "Inter" for clean modern readability, and a monospace font ("JetBrains Mono") for tech tags and system metrics.
- Text Hierarchy: Primary text in #F4F0EA (Warm Ice), secondary text in #9C93AB (Muted Lavender).
- Shapes: 16px border-radius for cards, 50px pill shape for buttons and badges.

Page Structure (One-Page Storytelling):

1. Header & Navigation:
   - Floating dark glass navbar with blur effect.
   - Left: Logo "SF" / "Saimon.dev".
   - Center: Nav links (Projetos, Arsenal, Sobre, Contato).
   - Right: Availability badge with a green pulsating dot "Disponível para novos projetos".

2. Hero Section:
   - Availability pill badge: "● Aberto a novos desafios".
   - High-impact headline: "Desenvolvedor Full Stack focado em interfaces elegantes e arquitetura de ponta a ponta".
   - Subtitle explaining the balance between refined UX/UI and robust backend architecture (PHP 8 MVC nativo, PostgreSQL, modern JS, CI/CD).
   - Action buttons: Primary gradient button "[Explorar Projetos]" (#6F00FF to #340094), and secondary dark outline buttons "[GitHub]" and "[LinkedIn]".

3. Featured Project Showcase (Symo Finance):
   - A wide highlight card showcasing "Symo Finance", a personal finance web platform.
   - Left/Top (Mockup Showcase): A realistic browser mockup showing the real-time financial dashboard with interactive tabs at the top: "[ 💻 Desktop ]" and "[ 📱 Mobile ]". Floating pill badges around the frame: "45 Telas Documentadas", "Concorrência Atômica", "Neon PostgreSQL".
   - Right/Bottom (Engineering Details): Title, brief value proposition, technical highlight bullets (Zero framework backend, native MVC, Neon PgBouncer pooler, audit trail with JSON Diff), and buttons: "[Ver Galeria]" and "[Testar Protótipo]".

4. Other Projects Section (Streaming-Style Horizontal Carousel):
   - Section title: "Outros Projetos em Destaque".
   - A Netflix/Amazon style horizontal slider with navigation arrows (prev/next).
   - Showing 3 cards visible at once:
     - Card 1: "Landing Page No Man's Sky" (Space-themed front-end, video background, smooth CSS transitions, responsive).
     - Card 2: "Projeto Full Stack" (Placeholder for upcoming web application).
     - Card 3: "API & Microserviço" (Placeholder for upcoming backend project).

5. Tech Arsenal (Skills by Layer):
   - Organized in 4 clean cards with sleek icons:
     - Front-end & UX/UI: HTML5, CSS3/Tokens, Vanilla JS (ES6+), Bootstrap, WCAG A11y, Micro-interactions.
     - Back-end & Architecture: PHP 8.2+ Nativo, MVC Pattern, REST APIs, Security Defense-in-Depth.
     - Databases: PostgreSQL (Neon Serverless), MySQL, ACID Atomic Transactions, Schema Migrations.
     - DevOps & Cloud: Vercel Serverless, Vercel Blob, GitHub Actions CI/CD, Git.

6. Footer & Contact:
   - Call to action card: "Vamos construir algo juntos?".
   - One-click copy email button with tooltip feedback.
   - Social links (LinkedIn, GitHub) and minimalist copyright.
```

1. Header & Navigation:
