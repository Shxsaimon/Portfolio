## Brand & Style
The portfolio balances high-order computational engineering with uncompromising visual craft. It targets engineering leads, venture founders, design directors, and premium clients seeking full-stack execution paired with bespoke interaction design. 

The aesthetic is rooted in dark-mode cyber-minimalism and refined glassmorphism:
- Deep nocturnal foundations paired with focused, intense photonic emissions.
- Tactile clarity: structural elements communicate precision, responsiveness, and algorithmic balance.
- Glass panels establish modular hierarchy, allowing ambient neon undercurrents to bleed through cleanly without introducing visual noise.
- Every interactive element signals high performance, low latency, and modern kinetic energy.

## Colors
The color framework relies on high-contrast spectral separation over a light-absorbent base:

- **Canvas & Surface Base:** Deep Obsidian (`#0A090D`) serves as the foundational canvas, absorbing distraction. Elevated surfaces utilize charcoal-tinted dark glass (`#14121A`) with varying alpha channel overlays.
- **Accents & Luminescence:** 
  - Primary Electric Violet (`#6F00FF`) drives primary CTAs, active indicators, and high-impact focal points.
  - Secondary Bright Orchid (`#8900B3`) and Tertiary Neon Magenta (`#8129D9`) construct dynamic linear gradients (`linear-gradient(135deg, #6F00FF 0%, #8129D9 100%)`) for hero typography highlights, ambient mesh glow backdrops, and active card edge strokes.
- **Content Hierarchy:**
  - Primary Text & Headings: Warm Off-White (`#F4F0EA`) guarantees peak readability without harsh pure-white eye strain.
  - Muted & Secondary Text: Lavender Slate (`#9C93AB`) handles subtext, dates, metadata, and structural outlines.
  - Borders & Hairlines: Translucent white strokes (`rgba(255, 255, 255, 0.08)`) frame default states, transitioning to bright orchid or violet glows upon interaction.

## Typography
The system employs an authoritative structural pairing: **Plus Jakarta Sans** delivers polished geometric humanist clarity for human-centered narratives, while **JetBrains Mono** surfaces computational authenticity for metrics, code architectures, and technical categorization.

- Headings demand tight tracking (`-0.03em` to `-0.01em`) to create dense, impactful editorial locks.
- Paragraphs run on generous line heights (`1.6`) set in `#9C93AB` for effortless scannability over dark surfaces.
- Technical indicators, badge elements, and architecture stack labels leverage JetBrains Mono with capitalized, tracking-spaced labels (`label-caps`) to invoke command-line sophistication.

## Layout & Spacing
A 12-column fluid grid system with controlled maximum constraints powers the portfolio interface:

- **Desktop (>= 1024px):** Max container width capped at `1280px` centered with dynamic margins (`margin-desktop: 4rem`), utilizing a 12-column grid with `2rem` gutters.
- **Tablet (768px - 1023px):** 8-column layout with `1.5rem` gutters and `2rem` horizontal margins.
- **Mobile (< 768px):** 4-column single-flow layout with `1.5rem` outer canvas padding and `1rem` column gaps.
- **Vertical Cadence:** Strict 8px increment system. Sections are separated by expansive vertical buffers (`space-2xl` to `space-3xl`) to let deep canvas glassmorphism breathe without claustrophobic crowding.

## Elevation & Depth
Depth is created through chromatic ambient emission and translucent glass stacking rather than conventional drop shadows.

- **Level 0 (Canvas Base):** Solid Obsidian (`#0A090D`) with passive, non-interactive radial gradients blurred in the background (`blur(120px)`) at `15%` opacity using `#6F00FF`.
- **Level 1 (Default Glass Surface):** Background `rgba(20, 18, 26, 0.7)` supported by `backdrop-filter: blur(16px)` and a crisp perimeter border `1px solid rgba(255, 255, 255, 0.08)`.
- **Level 2 (Hover / Elevated Cards):** Surface shifts to `rgba(28, 24, 38, 0.85)`, border shifts to `rgba(137, 0, 179, 0.6)`, and a diffuse outer photonic bloom activates: `box-shadow: 0 12px 32px -8px rgba(111, 0, 255, 0.25), 0 0 16px 0 rgba(137, 0, 179, 0.2)`.
- **Level 3 (Modals & Overlays):** Surface `#14121A` at `95%` opacity, `backdrop-filter: blur(24px)`, bounded by a `1px` gradient border, cast against a full backdrop dimmer of `rgba(10, 9, 13, 0.8)`.

## Shapes
The structural system uses precise geometry:
- Content containers, project cards, and code snippets use an exact corner radius of `16px` (`rounded-lg`), delivering a sleek, modern device-like silhouette.
- Interactive controls, buttons, tooltips, and category chips utilize full pill profiles (`rounded-full` / `50px`) to provide an organic, clickable contrast against angular grid modules.
- Nested micro-elements within cards (code badges, status dots, icon tiles) scale proportionally down to `8px` (`rounded-md`).

## Components

### Buttons
- **Primary Action (Pill, 50px radius):** Gradient background `linear-gradient(135deg, #6F00FF 0%, #8129D9 100%)`, text `#F4F0EA`, weight bold, vertical padding `0.875rem`, horizontal padding `1.75rem`. Hover state introduces an external glow `0 0 24px rgba(111, 0, 255, 0.5)` and subtle scale transform `scale(1.02)`.
- **Secondary Glass Action:** Translucent dark fill `rgba(255, 255, 255, 0.04)`, `1px solid rgba(255, 255, 255, 0.12)`, text `#F4F0EA`. Hover state transitions border to `#8900B3` and background to `rgba(137, 0, 179, 0.1)`.

### Project & Case Study Cards
- Bounded by `16px` border-radius and `1px` subtle outline (`rgba(255, 255, 255, 0.08)`).
- Card body uses `#14121A` with a subtle inner top light-bleed (`inset 0 1px 1px 0 rgba(255, 255, 255, 0.1)`).
- Interactive hover triggers a transition to border `#8900B3` with an outer electric glow and slight upward translate `translateY(-4px)`.

### Chips & Code Badges
- Tech stack indicators use `JetBrains Mono` at `label-code` spec.
- Pill-shaped or `6px` radius with `rgba(255, 255, 255, 0.05)` background and `rgba(255, 255, 255, 0.1)` border.
- Active or featured stack tags switch to violet-tinted backgrounds `rgba(111, 0, 255, 0.15)` with text in `#8129D9`.

### Interactive Metric Display
- Card modules pairing raw telemetry (e.g. `99.9%`, `<12ms`) in `JetBrains Mono` (`label-metric`) styled with gradient fills (`#6F00FF` to `#8129D9`), anchored by descriptive subheadings in `#9C93AB`.

### Form Fields & Inputs
- Pill or `12px` rounded inputs with background `rgba(20, 18, 26, 0.9)`, border `1px solid rgba(255, 255, 255, 0.1)`, placeholder in `#9C93AB`.
- Focus state removes native outlines, substituting border `#8900B3` and ring glow `0 0 0 3px rgba(111, 0, 255, 0.2)`.

### Live Terminal & Code Blocks
- Framed in `#0E0D13` with macOS-style micro-action dots.
- Code rendered in `JetBrains Mono` with electric syntax highlights (violet keywords, magenta strings, muted lavender comments).
