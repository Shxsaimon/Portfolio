# Saimon Furigo — Personal Portfolio

Portfólio pessoal e showcase de projetos e engenharia de software construído por **Saimon Furigo**.

## 🎯 Proposta & Arquitetura

O portfólio foi desenhado seguindo a metodologia **One-Page Storytelling**, combinando refinamento visual de Front-end (UX/UI) com a demonstração clara de competências técnicas em sistemas full-stack de ponta a ponta.

### Destaques Técnicos:
- **Design System com Tokens CSS Nativos:** Sem overhead ou dependências pesadas de frameworks front-end, garantindo alta performance e pontuação máxima no Google Lighthouse.
- **Device Frame Switcher:** Alternador responsivo interativo para visualização de projetos em formatos Desktop e Mobile.
- **Carrossel Horizontal de Projetos:** Navegação fluida para exploração dos trabalhos em destaque.
- **Acessibilidade & Semântica:** HTML5 estruturado segundo padrões WCAG e tipografia adaptada para alta legibilidade.

## 🛠️ Stack

- **Front-end:** HTML5 Semântico, CSS3 Moderno (Custom Properties / Design Tokens), JavaScript Vanilla (ES6+).
- **Tipografia:** Plus Jakarta Sans / Inter & JetBrains Mono.
- **Ícones:** Lucide Icons.
- **Deploy:** Vercel.
