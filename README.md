## 🎯 Proposta & Arquitetura

O portfólio foi desenhado seguindo a metodologia **One-Page Storytelling**, combinando refinamento visual de interface com uma demonstração transparente de competências técnicas em engenharia de software e arquitetura de sistemas.

### Destaques Técnicos & Interatividades Ativas:
- **Design System com Tokens Nativos (Obsidian Kinetic):** Cores, espaçamentos e superfícies estilizados via CSS Custom Properties, garantindo alta performance, leveza e ausência de lock-in de frameworks pesados.
- **Device Frame Switcher & Lupa Dinâmica:** Alternador entre mockup Windows Desktop e Smartphone Mobile no projeto em destaque (*Symo Finance*), incluindo ampliação dinâmica (zoom de até 1.9x) centrada na posição do cursor do mouse.
- **Carrossel Horizontal com Drag-to-Scroll & Loop Circular:** Navegação fluida para exploração de projetos com suporte a clique e arraste de mouse no desktop, swipe em telas sensíveis ao toque e navegação circular pelas setas.
- **Modal Nativo de Detalhes (`<dialog>`):** Visualização expandida de projetos reais utilizando a tag semântica `<dialog>` do HTML5, gerenciamento nativo de foco, top-layer isolado e fechamento por botão, clique no backdrop ou tecla `Esc`.
- **Cópia de E-mail em 1 Clique:** Interação com feedback visual temporário (`"Copiado!"`) integrado à API de Clipboard.

## 🛠️ Stack Técnica

- **Linguagens & Base:** HTML5, CSS3 com Design Tokens, JavaScript Vanilla (ES6+).
- **Tipografia:** Plus Jakarta Sans (corpo/display) e JetBrains Mono (tags e dados técnicos).
- **Ícones:** Material Symbols Outlined.
- **Hospedagem & Deploy:** Vercel.
